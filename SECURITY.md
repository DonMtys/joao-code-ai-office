# Security

- Never commit API keys or a populated `.env` file.
- The local bridge binds to `127.0.0.1` by default.
- The public GitHub Pages build runs only the scripted visual demonstration.
- Real agent execution requires an explicit click and a locally configured backend.
- The AI Gateway enforces the configured monthly budget before paid calls.

If you find a vulnerability, report it privately through the repository owner's
GitHub profile instead of publishing credentials or exploit details in an issue.
